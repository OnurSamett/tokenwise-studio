How it works

One orchestrator. A whole team of models.

Grepping a repo doesn't need your strongest model. Debugging a race condition does. tokenwise studio makes that call for every piece of the job.

01

Describe or dictate the task

Type or dictate in the composer, pick an orchestrator or team preset, or steer a single message with @codex, @sol, or @gemini.

02

Right model, right effort

Each writing worker runs in its own git worktree with the model and effort it needs—or as a parallel model shootout when you ask for one.

search · summariesHaiku · low
routine codeCodex Sol · medium
hard bugs · designOpus · high
03

Check conflicts, then apply

Review per-file diffs with conflict detection, run tests in the worktree, stage with one-click Undo Apply, or open a PR.

Features

Built for long sessions and shared plans.

⇄

Composer pickers & @mentions

Switch orchestrator model and effort (⌘/) with live limit hints, tune roles in the Team popover, or route one turn with @mentions.

↪

Quota pacing & fallback

Cooldowns track reset times so limited providers are skipped. Workers fall back along codex → gemini → claude → free → local, while the orchestrator can fall back along claude → codex → gemini → free → local.

◫

Workspace side panel

Browse project files, inspect diffs, preview images and pages, and view the This chat tab for files touched in the current conversation.

✓

Conflict check, Undo & PRs

Overlapping edits are flagged before Apply. Snapshots power one-click Undo Apply, and a confirm step opens a pull request via gh.

⚔

Model shootout

When you ask for a comparison, the same task goes to two or three models in parallel worktrees so you can pick the best diff.

$0

Free & local workers

Free mode runs the orchestrator and workers on free or local models. Opt-in NVIDIA models are ranked by Terminal-Bench 4.0; local Ollama runs on your hardware in Codex --oss mode.

⌘

Chat folders & ⌘K palette

Pin and organize chats into folders with date groups. Press ⌘K to jump across chats, folders, files, and actions, or ? for shortcuts.

🎙

Mac app, restore & dictation

Restores your last projects or shows a welcome window, sends app-only notifications straight to the right project, and includes composer dictation.

▤

Usage, tests & Turkish UI

14-day token and API-equivalent cost charts, worktree and combined post-apply checks, turn budgets, and English or Türkçe (Auto) across UI and alerts.

Get it

Two ways to use tokenwise.

Use the skill inside the agent you already like, or the studio to run a whole team from one screen. They work great together, and each works on its own.

App

tokenwise studio

A Mac app and local web UI: one orchestrator, many workers, side panel, per-file review, and live plan limits.

Download for Mac

Drag the app to Applications. Includes Node.js for Apple Silicon and Intel Macs (macOS 13.3+). Needs git and a signed-in worker CLI.

Or install the CLI with Node.js 20+ already installed:

curl -fsSL https://tokenwise.site/install.sh | sh

The installer checks Node, installs the CLI, runs setup, and opens the app. It never installs Node automatically.

Download for Windows (beta)

Extract the entire zip to a writable folder and run TokenwiseStudio.exe. Node.js and .NET are included. Install git and a signed-in worker CLI separately. If WebView2 is missing, the app links to Microsoft's Evergreen installer.

Unsigned beta: SmartScreen: More info → Run anyway. Not yet tested on real Windows hardware. Native dictation, Roblox playtest and Sparkle automatic updates are Mac-only and hidden on Windows. Notifications use the browser Notification API; click the bell to grant permission and enable them. Keep the app open to receive them. To update, download the latest zip.

Alternative browser CLI installer (requires Node.js 20+ and git), in PowerShell:

irm https://tokenwise.site/install.ps1 | iex

Then run tokenwise-studio.cmd --browser in a project folder. This one-liner installs the CLI; the desktop download bundles its own runtime.

  • Sign in to Claude Code, Codex CLI, Antigravity, or Gemini CLI with an API key. tokenwise-studio doctor checks workers.
  • Free & local workers: add an NVIDIA API key (opt-in) or Ollama (gpt-oss:20b).

FAQ

Questions

Is it free?

Yes. tokenwise and tokenwise studio are open source (MIT). They run on your machine and use the plans and CLIs you already have; there is no tokenwise account or server.

Does it save usage, really?

On small tasks the overhead is about even; the savings come from long sessions with lots of reading, where mechanical work goes to cheaper models and other plans. The Model guide links to benchmark data; the Usage screen helps you compare tokens and API-equivalent costs on your own work. Subscription plans are not billed by those estimates.

Will my code be sent to free providers?

Only if you opt in. Hosted free models require a provider key and opt-in through Settings or TOKENWISE_ALLOW_FREE=1, because free tiers may use prompts for training. Their file tools block secret files such as .env. Prompts and text you paste are still sent to the provider you choose.

Can a worker break my project?

Writing workers stay in their own git worktree. Before Apply, studio checks for overlapping edits between workers; Apply stages only ticked files without committing, and every Apply records a snapshot for one-click Undo Apply.

What happens when Claude runs out?

At the configured limit threshold (90% by default), or on a mid-turn limit, the orchestrator can continue on the next available provider: claude → codex → gemini → free → local. It keeps the conversation and review tools. Settings lets you switch automatically, ask first, or turn switching off. Free providers require opt-in and credentials; local models require Ollama. Cooldowns also pause limited providers until their reset time. Turn orchestrator fallback off with TOKENWISE_ORCH_FALLBACK=0.

Do notifications need anything?

On macOS, notifications come directly from the tokenwise studio app after tokenwise-studio setup. On Windows, click the sidebar bell to allow browser notifications and keep the UI open. The bell toggles notifications; clicking one focuses its project.

What do I need?

Node 20+, git, and at least one of Claude Code, the Codex CLI or Google Antigravity (or Gemini CLI with GEMINI_API_KEY), signed in. macOS is the primary platform: the app restores your last projects on launch or shows a welcome window. Windows has an unsigned WebView2 desktop beta with bundled Node.js and .NET, plus a browser CLI. Native dictation, Roblox playtest and Sparkle updates are Mac-only. Windows has not yet been tested on real hardware.
